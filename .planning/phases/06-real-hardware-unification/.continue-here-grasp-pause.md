## Decisions made today (with rationale)

1. **Real mode uses hardcoded gripper open/close, NOT bbox-driven dynamic
   calculation**. Reason: yoloe bbox accuracy is noisier than sim ground
   truth; a single hand-tuned pair is more reliable for repeated lego
   grasps. Spinboxes let the user adjust live. (A.12)

2. **Per-joint freedrive + recenter via in-process jsr services, not
   external scripts**. Reason: avoids the 4-5 sec /joint_states blackout
   from killing+respawning jsr. RViz mirrors arm motion live throughout.
   (A.9)

3. **lerobot JSON path is so_follower/, NOT so101_follower/, despite
   `--robot.type=so101_follower` CLI flag**. Reason: lerobot 0.5.2's flag
   configures the runtime robot CLASS but the JSON save path is
   independent. A.5 mistakenly changed paths; A.10 reverted.

4. **Connect/Disconnect ≠ Freedrive — they control orthogonal things**.
   Connect/Disconnect controls bus ownership (who can write
   /joint_commands). Freedrive controls servo torque state. Two different
   axes, two different buttons.

5. **All tabs scroll, not just Settings**. Reason: any tab can grow past
   one screen height as features are added; uniform scrolling avoids
   per-tab maintenance burden later. (UX)

6. **±4095 Homing_Offset guard, not ±2047**. Reason: Feetech firmware
   empirically accepts up to one full encoder rotation. Tighter cap blocked
   legitimate big-correction recovery (e.g. undoing an over-rotated
   recenter). (A.11)

## Gotchas discovered (and fixed) today

1. **EEPROM/JSON divergence**: A.10's path bug meant earlier recenter calls
   updated EEPROM but failed JSON write silently. Some joints had EEPROM
   Homing_Offsets 2400+ ticks off from JSON. Manually synced via inline
   Python script. Future recenters should keep them in sync.

2. **Freedrive cable-harness drift**: when wrist_roll torque turns off,
   gripper cables exert spring force that rotates the joint silently
   during the freedrive window. Workaround: skip freedrive_one and call
   recenter_one directly with torque ON (servo holds steady).

3. **torque_reset gravity-droops the arm**: 700ms torque-off lets
   shoulder_lift fall ~17° and elbow_flex bend ~13° under gravity. The
   anti-jolt at the end captures the drooped pose. Don't use torque_reset
   when arm is extended in air without support.

4. **lerobot wizard skips wrist_roll's Homing_Offset, leaves at 0**.
   Empirical: post-calibrate JSON shows wrist_roll homing=0 even when STEP
   1 should have recorded a non-zero pose. So wrist_roll always needs a
   separate Set Zero (recenter_one) after calibrate.

5. **macOS spaces in repo path break shell command construction**: A.8
   discovered three Terminal-launching buttons f-stringed unquoted paths.
   shlex.quote(path) produces single-quoted form that survives bash
   word-splitting AND doesn't conflict with AppleScript's outer
   double-quotes.

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention |
|---------|-------------|----------|---------|
| Bypass added at wrong layer | A.12 added real-mode short-circuit inside `_gripper_angle_for_object` but missed that the caller (`_cmd_gripper_open_for_object`) had its own bbox precondition that bypassed the short-circuit. A.13 fixed by also adding mode-check at the caller layer. | advisory | When adding mode-specific behavior to a function, trace ALL callers to verify they don't have preconditions that block the new mode. |
| Path drift between docs and reality | A.5 changed paths from so_follower/ to so101_follower/ based on documentation reading without empirical verification. A.10 reverted after probing the actual filesystem. | advisory | When touching filesystem paths in multiple files, verify against `ls`/`find` actual paths before committing. |
| Cap based on conservative datasheet reading | A.11 had a ±2047 Homing_Offset cap based on one Feetech datasheet's "12-bit signed" interpretation. Firmware empirically accepts ±4095. Cap blocked legitimate operations. | advisory | When implementing safety guards, prefer empirical limits over conservative datasheet readings. Document the empirical evidence. |
